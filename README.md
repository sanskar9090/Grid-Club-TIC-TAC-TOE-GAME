# Grid Club — Tic Tac Toe

A responsive Tic Tac Toe game built with plain HTML, CSS, and JavaScript.

## Features
- Two-player mode
- Play against the computer
- Win and draw detection
- Scoreboard, undo, and new game controls
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
The included GitHub Actions workflow deploys the site when Pages is enabled for this repository. In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. The workflow will then publish the site automatically.
